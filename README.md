# aiscan — AI iz / imza / watermark tarayıcısı

> **English:** aiscan finds the traces AI tools leave in a codebase: explicit signatures and co-author
> trailers, bot authors in git history, invisible Unicode watermarks (and decodes the hidden payload),
> binary metadata, leaked assistant text and stylistic fingerprints. Fully local, no network access, no
> dependencies beyond the Python 3.9+ standard library; 89 rules, 4 engines, 6 report formats including SARIF.

Bir kod tabanında **yapay zekânın bıraktığı her türlü izi** bulur: açık imzalar
(`Generated with Claude Code`, `Co-Authored-By: Claude`), git geçmişindeki bot
yazarlar, **gözle görülmeyen Unicode watermark'ları** (ve içindeki gizli mesajı
çözer), ikili dosya metadata'sı, asistan metni sızıntıları ve üslup parmak izleri.

* **Tamamen yerel / on-prem.** Hiçbir ağ bağlantısı yoktur, hiçbir veri dışarı çıkmaz.
* **Sıfır bağımlılık.** Yalnızca Python 3.9+ standart kütüphanesi.
* **89 kural + 4 ayrı motor.** Metin, Unicode, ikili metadata, git geçmişi.
* **6 çıktı formatı.** Terminal, HTML, JSON, Markdown, CSV, SARIF.

Kurulum gerekmez, doğrudan çalışır:

git clone https://github.com/90karatinsa/aiscan.git

| `Co-Authored-By: Claude <noreply@anthropic.com>` | AI-ATTR-002/003 |
| `Co-authored-by: Cursor / Copilot / Devin / aider ...` | AI-ATTR-006 |
| `# This file was generated by an AI assistant` | AI-ATTR-008 |
| `created with GitHub Copilot / Windsurf / v0 / Bolt ...` | AI-ATTR-009 |
| `chatgpt.com/share/...`, `claude.ai/code` bağlantıları | AI-ATTR-012 |
| Base64 **içine gizlenmiş** imza (çözülüp gösterilir) | AI-ENC-001 |

40'tan fazla AI aracı adı tanınır (Claude Code, Copilot, Cursor, Codex, Gemini CLI,
Devin, aider, Cline, Roo, Windsurf, Amazon Q, Tabnine, v0, Bolt, Lovable, Replit
Agent, OpenHands, Goose, Antigravity, Jules ...).

### 2. Görünmez Unicode watermark (`hidden-unicode`) — en kritik katman

Gözle **hiçbir şekilde** görülemeyen izler. aiscan bunları bulmakla kalmaz,
**taşıdıkları gizli mesajı geri çözer**:

| Teknik | Ne yapar | Kural |
|---|---|---|
| Unicode TAG karakterleri (U+E0000–U+E007F) | Doğrudan ASCII'ye çözülür | AI-UNI-001 |
| Varyasyon seçicileri (U+FE00–FE0F, U+E0100+) | Emoji içine gizlenmiş baytlar çözülür | AI-UNI-002 |
| Sıfır genişlikli karakter dizisi (ZWSP/ZWNJ/ZWJ) | 9 farklı ikili şema, 7/8 bit denenir | AI-UNI-003 |
| Bidi kontrol karakterleri | "Trojan Source" saldırısı | AI-UNI-004 |
| Tekil görünmez karakterler | Soft hyphen, word joiner, hangul filler ... | AI-UNI-005 |
| Homoglif (karışık alfabe) | Latin kelimeye sızdırılmış Kiril/Yunan harfi | AI-UNI-007 |
| Yoğunluk analizi | Dosya genelinde sistematik işaretleme | AI-UNI-008 |

Örnek çıktı:

```
KRITIK  AI-UNI-001      1:23  Unicode TAG karakteri ile gizlenmis metin
          eslesme: 17 adet U+E00xx TAG karakteri
          detay  : COZULEN GIZLI METIN: 'Claude Code yazdi'

KRITIK  AI-UNI-003      2:17  Sifir genislikli karakter dizisi (kodlanmis yuk)
          detay  : COZULEN GIZLI METIN: [8-bit, U+200B=0 / U+200C=1 (tam)] -> 'AI2026'
```

### 3. Git geçmişi provenance (`provenance`)

Kod temizlenmiş olsa bile geçmiş iz tutar:

* Commit yazarı / commit'leyen bir AI ajanı mı (`AI-GIT-001`)
* `noreply@anthropic.com`, `@openai.com`, `copilot@` gibi servis adresleri (`AI-GIT-005`)
* Commit mesajındaki imzalar ve trailer'lar (`AI-GIT-002`)
* Ajan dal adları: `claude/...`, `codex/...`, `cursor/...` (`AI-GIT-006`)
* Depo `git config`'inde kalmış AI kimliği (`AI-GIT-007`)
* `.git/COMMIT_EDITMSG`, `.git/hooks/*` içindeki izler (`AI-GIT-008/009`)

### 4. İkili dosya ve doküman metadata'sı (`metadata`)

| Format | Bakılan yer |
|---|---|
| PNG | `tEXt`/`iTXt`/`zTXt` blokları, `parameters`, `prompt`, `workflow`, C2PA `caBX` |
| JPEG | EXIF `Software`/`Artist`/`UserComment`, XMP paketi, yorum segmenti |
| PDF | `/Producer`, `/Creator`, gömülü XMP |
| Office / ODF / EPUB | `docProps/core.xml`, `app.xml`, `meta.xml` |
| Her ikili dosya | Ham gövdede AI belirteci araması |

Stable Diffusion, ComfyUI, Midjourney, DALL·E, Firefly, NovelAI üretim
parametreleri ve **C2PA "Content Credentials"** (AI üretim beyanı) tanınır.

### 5. Asistan metni ve prompt sızıntısı (`assistant-leak`, `prompt-leak`)

`As an AI language model`, `I'm sorry, but I cannot`, `knowledge cutoff`,
`<|im_start|>`, `[/INST]`, `### Instruction:`, `You are a helpful assistant`,
`Certainly! Here's the updated code` ve benzeri kalıplar.

### 6. Kod atlama kalıntıları (`placeholder`)

AI'ın kod yazarken atladığı yerleri işaretleyen ve **derlenmeyen kod** bırakan
kalıplar: `// ... rest of the code unchanged`, `# Add your code here`,
`TODO: implement`, `<<<<<<< SEARCH` (aider blokları), `your_api_key_here`.

### 7. Üslup ve tipografi parmak izi (`stylometry`, `typography`)

İstatistikseldir, **tek başına kanıt değildir**: em-tire yoğunluğu, kıvrık
tırnaklar, kırılmayan boşluklar, `delve`/`leverage`/`seamless`/`robust` gibi
LLM favori kelimeleri, `Step 1:` kalıbı yorumlar, emoji başlıklar.
Rapor bunları ayrı bir "üslup sinyalleri" bölümünde toplar.

## Çıktılar

```bash
aiscan /proje --out-dir ./rapor      # altı formatın hepsi
aiscan /proje --html rapor.html      # tek dosyalık, filtrelenebilir HTML
aiscan /proje --json bulgular.json   # makine okunur
aiscan /proje --sarif out.sarif      # CI / GitHub code scanning
aiscan /proje --csv tablo.csv        # Excel
aiscan /proje --md rapor.md          # Markdown
```

HTML raporu arama kutusu ve şiddet filtresi içerir, koyu/açık temaya uyar,
tek dosyadır ve dış kaynak yüklemez.

Her bulgu şunları verir: **dosya yolu, satır:sütun, kural kimliği, şiddet,
eşleşen metin, satırın kendisi, çözülmüş gizli yük ve açıklama.**

## Yanlış pozitifleri yönetme

`.aiscanignore` dosyası (taranan dizinin kökünde):

```
# yol deseni
vendor/*
docs/eski/*

# belirli bir kuralı belirli bir yolda sustur
AI-ATTR-014:src/llm/*
AI-TYPO-001:*.md
```

Satır bazında susturma — satırın sonuna yazmanız yeterli:

```python
x = 1  # Generated with Claude Code   aiscan:ignore
```

Baseline (mevcut durumu kabul et, yalnızca yenileri göster):

```bash
aiscan /proje --write-baseline .aiscan-baseline.json
aiscan /proje --baseline .aiscan-baseline.json
```

> **LLM ile ilgili projeler için not:** Bir LLM istemcisi, sohbet şablonu veya
> model yönlendirici geliştiriyorsanız `AI-ATTR-014` (model kimlikleri) ve
> `AI-LEAK-009` (sohbet şablonu jetonları) doğru ama beklenen bulgular üretir.
> `--disable AI-ATTR-014,AI-LEAK-009` ile kapatın.

## Sık kullanılan seçenekler

| Seçenek | Açıklama |
|---|---|
| `--min-severity high` | Yalnızca ciddi bulgular |
| `--category hidden-unicode` | Tek bir kategoriye odaklan |
| `--only AI-ATTR-001` | Tek bir kural |
| `--disable KURAL,KURAL` | Kural(lar)ı kapat |
| `--no-git` / `--no-binary` | İlgili motoru kapat |
| `--all-files` | `.gitignore` ile dışlananları da tara |
| `--git-all` | Tüm dallardaki commit'leri tara |
| `--jobs 10` | Paralel süreç sayısı |
| `--fail-on critical` | CI için: bulgu varsa çıkış kodu 1 |
| `--limit 0` | Terminalde tüm bulguları göster |
| `--list-rules` | Kural kataloğunu yazdır |

## CI entegrasyonu

```bash
aiscan . --min-severity high --fail-on critical --sarif aiscan.sarif --quiet
```

Çıkış kodları: `0` temiz/eşik altı, `1` eşik üstü bulgu, `2` kullanım hatası.

## Mimari

```
aiscan/
  rules.py         89 kurallık katalog (kimlik, şiddet, kategori, desen)
  textscan.py      iki kademeli regex motoru + base64 çözümleyici
  unicodescan.py   görünmez karakter tespiti ve gizli yük çözücüleri
  binmeta.py       PNG / JPEG / PDF / Office / C2PA metadata okuyucuları
  gitscan.py       commit, yazar, dal, config ve .git artifact taraması
  walker.py        dosya keşfi, ikili tespiti, paralel yürütme
  report.py        terminal / HTML / JSON / Markdown / CSV / SARIF
  cli.py           argümanlar, filtreler, baseline, çıkış kodları
```

**Hız:** Tüm kurallar tek bir "master" regex'te birleştirilir; dosyaların büyük
çoğunluğu tek geçişte elenir, 89 kural yalnızca aday satırlarda tek tek çalışır.
Ölçüm: 2.590 dosya / 108 MB / 2.000 commit → **~37 saniye** (10 çekirdekli Mac).

**Kendi kendini tarama:** aiscan'in kendi kaynağı kural desenlerini içerdiği için
varsayılan olarak taramanın dışında tutulur. `--include-self` ile dahil edilebilir.

## Sınırlar — dürüstçe

* **Üslup analizi olasılıksaldır.** `DUSUK` şiddetli bulgular tek başına
  "bu kodu AI yazdı" demez; ancak `KRITIK` bulgular (açık imza, çözülmüş gizli
  Unicode yük, bot commit yazarı) tesadüfle açıklanamaz.
* **İz bırakmayan AI'ı tespit edemez.** Bu araç *bırakılmış izleri* bulur;
  temiz yazılmış ve elle düzenlenmiş kodun kaynağını kanıtlayamaz.
* **Bulgu ≠ suçlama.** Bir `.claude/` dizini veya `CLAUDE.md`, o dosyanın
  varlığını gösterir; kodun tamamının üretildiğini değil.
